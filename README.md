# AWS Hackathon — Student Career Planning Website

## About
A student-focused career planning website that helps students explore career pathways, plan skill development, and discuss career decisions with their families.

## Features
- Career pathways and roadmaps
- Skills and career planning
- Student priorities and concerns
- Family discussion workspace
- Options comparison and tentative decisions
- Discussion notes

## Technology
Built with the web technologies and dependencies listed in `package.json`.

## Run Locally
1. Install Node.js.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Deployment
The project can be deployed using Netlify by connecting the GitHub repository and configuring the build settings.

## Purpose
Developed as an AWS hackathon project.
